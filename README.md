# aerokastell-website

The AeroKastell website: a single landing page (English and German) plus the Impressum pages.

Built with plain HTML and CSS: no frameworks, no JavaScript, no build step.
The Lato fonts are self-hosted (SIL Open Font Licence) and all brand assets
come from the official brand repository.

To edit the page, open `index.html` and change the text. The styles are
inline in the same file.

Keep the two languages in step: `index.html` (English) and `de/index.html`
(German) share the same structure and the same styles; change both.

Copy rules:

- The survey figures (54.7 % and 46.5 %) are for the 86 of 104 operators who see
  drones as a threat; keep that qualifier and the source line with them.
- The "Overflight record" card is an illustration of the concept, not a product
  screen; keep its label.
- The link preview image is `assets/ak-og-image-v03.png` (1200 x 630).
